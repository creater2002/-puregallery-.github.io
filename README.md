# PURE GALLERY — магазин холстов

Готовый статический сайт для публикации на GitHub Pages. Технологии: HTML, CSS, JavaScript. Сборка и сервер не нужны.

## Публикация на GitHub Pages
1. Создайте публичный репозиторий на GitHub, например `pure-gallery`.
2. Распакуйте архив и загрузите **все файлы и папку `images`** в корень репозитория.
3. Перейдите в Settings → Pages.
4. В Build and deployment выберите `Deploy from a branch`, ветку `main`, папку `/ (root)`, затем Save.
5. Сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/pure-gallery/`.

## Персонализация — обязательно перед запуском
Откройте `script.js`, в начале найдите `const STORE`:
- `currency: "USD"` — валюта уже настроена на доллары.
- `telegram` — замените `https://t.me/your_telegram` на ваш контакт.
- `email` — замените `hello@example.com` на рабочий адрес.
- `products` — замените названия, категории, цены, количество `stock` и доступные `sizes`.
- Для каждого товара поменяйте путь `image` на своё фото. Например, положите фото в папку `images` и укажите `images/my-canvas.jpg`.

## Собственные фотографии
Сейчас в `images/` находятся временные SVG-заглушки с пометкой REPLACE WITH YOUR PHOTO. Они нужны, чтобы каталог не выглядел сломанным до загрузки ваших фотографий. Замените изображения своими фотографиями и поправьте пути в `script.js`. Рекомендуется вертикальный кадр 4:5, хорошее естественное освещение и одинаковая обработка фотографий.

## Что настроено
- Бренд PURE GALLERY, валюта USD.
- Каталог с категориями, сортировкой, выбором размера и остатками.
- Корзина с расчётом предварительной суммы.
- Заявка с контактами и адресом.
- Условия: почтовая доставка по Европе и самовывоз по договорённости; банковский перевод после подтверждения наличия.
- Адаптивная версия для смартфонов.

## Важные ограничения текущей версии
Форма заказа открывает почтовое приложение клиента и подготавливает письмо на `STORE.email`. Она не отправляет заявку на сервер автоматически, не хранит заказы и не принимает онлайн-платежи. Для автоматического приёма заявок подключите Formspree / Netlify Forms или серверную часть. Для банковских переводов отправляйте покупателю реквизиты только после подтверждения заказа. Не помещайте секретные ключи в публичный JavaScript.

Перед продажами заполните точные сроки и стоимость почтовой доставки по странам Европы, адрес/условия самовывоза, правила возврата, юридические сведения продавца и политику конфиденциальности. Убедитесь, что валюта USD действительно подходит для вашей аудитории и банковских расчётов.
